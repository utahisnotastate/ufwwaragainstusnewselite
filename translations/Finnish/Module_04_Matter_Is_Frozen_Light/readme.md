Se on tehty savusta, mutta se pitää muotoaan, eikö? Se pyörii ympyrää (pyörre).Fotoni (valo) haluaa juosta suoraa linjaa valon nopeudella.Elektron (aine) on sama fotoni, joka on pakotettu juoksemaan tiukassa pienessä ympyrässä.Loukku: Koska se pyörii ympyrää niin nopeasti, se pysyy yhdessä paikassa.
