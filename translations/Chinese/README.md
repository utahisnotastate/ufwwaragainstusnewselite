# 2420 年代的「失落」课程 — 为人类讲解显而易见的物理学

这是一套图文并茂、通俗易懂的课程，讲授 Earth-1 物理学传统的核心公理。每个模块将儿童友好的课程与简洁、形式化的「物理学证明」配对。目标是清晰：短段落、强隐喻、专业排版，在保留技术意图的同时激发探索。

可将本仓库用作阅读顺序、教学工具包或进一步研究的种子。从第 1 模块开始按顺序学习 — 概念逐步递进。

---

## 内容概览

- 12 个主题模块，每个包含：
  - 课程 `readme`，为聪明的 8 岁儿童和好奇的成年人简化。
  - `PHYSICS_PROOF.md`，含结构化章节：`给 8 岁孩子`、`主题`、`公理`、`机制` 和 `证明/推论`（或 `结果`）。
- 一致的排版、间距和标题，便于快速浏览。
- 适用时附有鲜活的「ZEO-Architect 分析」笔记。

---

## 如何使用本课程

1. 阅读每个模块的 `readme`，了解故事、隐喻和直观图景。
2. 浏览对应的 `PHYSICS_PROOF.md`，把握思想的精炼结构。
3. 根据需要回顾较早的模块 — 后续课程会引用并扩展先前的公理。
4. 使用下方模块索引快速跳转。
