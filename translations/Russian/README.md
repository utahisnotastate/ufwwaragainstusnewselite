# «Утраченная» учебная программа 2420‑х — очевидная физика для людей

[![tests](https://github.com/utahisnotastate/ufwwaragainstusnewselite/actions/workflows/tests.yml/badge.svg)](https://github.com/utahisnotastate/ufwwaragainstusnewselite/actions/workflows/tests.yml)

☕ Поддержать проект: [ko-fi.com/utah23](https://ko-fi.com/utah23) · Зачем я это сделал: [ABOUT.md](ABOUT.md)

Двенадцать больших идей, каждая из которых преподаётся тремя способами:

| Слой | Файл | Что это |
|---|---|---|
| 📖 **История** | `readme.md` | Урок, написанный так, будто из школы 2420 года, для сообразительных восьмилетних и любознательных взрослых. Научная фантастика вокруг настоящего вопроса. |
| 🔬 **Наука** | `SCIENCE.md` | Проверка реальностью 2025 года: что установлено, где утверждение истории ломается (с числами) и что должно было бы быть правдой, чтобы оно сработало. С настоящими ссылками. |
| 🧪 **Лаборатория** | `simulation.py` | Запускаемый Python, который считает каждое число на научной странице. Проверен по учебным пределам и опубликованным измерениям. *(Код лабораторий лежит в английских модулях в корне репозитория.)* |

В каждом модуле также остаётся внутримировой `PHYSICS_PROOF.md`: собственный аргумент архива 2420 года, явно помеченный как часть истории.

**Зачем такой формат?** Истории — крючок. Они задают вопросы, которые дети действительно задают: *Правда ли, что космос пуст? Почему гравитация тянет? Можно ли перемещаться мгновенно?* Научные страницы отвечают честно, включая «нет, и вот расчёт, который это показывает». Узнать, где красивая идея ломается, учит физике больше, чем утверждение, что она работает.

---

## Быстрый старт

```bash
python -m pip install -r requirements.txt
python Module_02_Gravity_Is_Pushing/simulation.py   # запустить одну лабораторию
python -m pytest                                    # проверить все лаборатории
```

Нужен Python 3.10+ с NumPy и SciPy. Библиотека построения графиков и интернет не требуются. Команды запускают из **корня репозитория** (английские лаборатории).

## Участие

Самый ценный вклад — исправления: неверное число, пропущенная оговорка, лучшая ссылка. См. [CONTRIBUTING.md](CONTRIBUTING.md) о структуре модуля и правилах для кода и цитирования.

## Замысел

Эта программа использует научную фантастику, чтобы сделать вопросы физики неотразимыми, а затем отвечает на них честно. Истории — воображаемые; научные страницы и код стремятся быть корректными. Если найдёте место, где это не так, пожалуйста, откройте issue.
