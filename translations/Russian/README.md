# «Утраченная» учебная программа 2420-х — очевидная физика для людей

Красиво иллюстрированная учебная программа на простом языке, которая преподаёт основные аксиомы физической традиции Earth‑1. Каждый модуль сочетает детский урок с кратким, формализованным «физическим доказательством». Цель — ясность: короткие абзацы, сильные метафоры и профессиональное оформление, которое приглашает к исследованию, сохраняя технический смысл.

Используйте этот репозиторий как последовательность для чтения, набор для преподавания или семя для дальнейших исследований. Начните с модуля 1 и двигайтесь по порядку — понятия выстраиваются постепенно.

---

## Что внутри

- 12 тематических модулей, каждый с:
  - Уроком `readme`, упрощённым для сообразительных 8‑летних и любознательных взрослых.
  - `PHYSICS_PROOF.md` со структурированными разделами: `Для восьмилетнего`, `Тема`, `Аксиома`, `Механизм` и `Доказательство/Следствие` (или `Результат`).
- Единая типографика, интервалы и заголовки для удобного просмотра.
- Живой раздел «Анализ ZEO‑Architect» там, где это уместно.

---

## Как пользоваться этой программой

1. Читайте `readme` каждого модуля — историю, метафоры и интуитивную картину.
2. Просматривайте соответствующий `PHYSICS_PROOF.md` для сжатой структуры идеи.
3. При необходимости возвращайтесь к более ранним модулям — поздние уроки ссылаются на прежние аксиомы и развивают их.
4. Используйте указатель модулей ниже, чтобы быстро перейти в любое место.
