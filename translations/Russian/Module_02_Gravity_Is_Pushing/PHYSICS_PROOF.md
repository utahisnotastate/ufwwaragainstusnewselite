# Гравитация толкает — физическое доказательство

## Для восьмилетнего
«Ты не падаешь вниз — тебя вдавливают. Земля как зонтик: она блокирует дождь космического давления снизу. Дождь сверху давит тебя вниз».

## Тема
Энтропийная гравитация через затенение масс.

## Аксиома
Гравитация — не внутреннее притяжение между массами. Это эффект затенения всепроникающего космического потока.

## Механизм
- Космический поток (потоки виртуальных частиц/квитонов) бомбардирует все объекты со всех направлений.
- Две массы (M1 и M2) экранируют друг друга от этого потока. Между ними давление снижается; снаружи остаётся полное давление.
- Возникающий перепад давления сжимает массы вместе.

## Опровержение сопротивления
Стандартные возражения (например, сопротивление типа Ле Сажа для орбитальных тел) предполагают ускоренный поток пространства. При стационарном, изотропном потоке постоянной скорости суммарное сопротивление может не возникать.
