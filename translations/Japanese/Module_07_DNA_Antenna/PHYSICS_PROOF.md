# DNAはアンテナである — 物理学証明

> 📜 **作中文書。** これは2420年アーカイブの論証であり、物語の一部として残されています。科学的な意味での証明ではありません。この論証がどこで破綻するかを含む、検証済みの版は [SCIENCE.md](SCIENCE.md) にあります。

## 8歳児向け
「DNAはレシピだけじゃない — アンテナだよ。体は細胞が何になるか教える場を聞いている。音楽がダンサーに動き方を教えるように。」

## 主題
分裂放射能とファントム葉効果。

## 公理
DNAは液晶アンテナで、時間チャンネル（超常的チャンネル）を介して情報を送受信する。生物学はバイオホログラム — 分子より先に存在し導く情報場 — によって組織化される。

## メカニズム
- 分裂放射能：Gurwitsch（後に Kaznacheyev）が細胞が UV 光子で通信することを観察した。化学的接触を遮断して UV のみ許可すると、死にゆく培養が健康な培養に「死のパターン」を伝達できる。
- ファントム葉：高周波電気写真（キルリアン）では、生物の一部を切断しても、しばらくエネルギー輪郭が残る — 場が第一で物質が第二であることを示唆する。
- 光子消音：時間チャンネルの議論と同様、環境光がこのバイオ信号を消す。暗室または低光子条件が、時間‑心が DNA‑アンテナを駆動するのを観察するために必要である。

## 証明/含意
Kaznacheyev の細胞病理効果伝達とファントム葉写真は、生物学を導く非局所情報テンプレートを示唆する。
