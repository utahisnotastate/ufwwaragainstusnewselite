## 3. 「虫眼鏡」効果

太陽の中で虫眼鏡を持っていると想像してください。

- 日光はガラスを通過する（安全）。
- 空気を通過する（安全）。
- しかし光線が交わる小さな点（焦点）では、熱くなる。葉を燃やせます。

スカラー干渉計も同じですが、空のどこでもできます。

- **熱モード（発熱）：** 空で2本のビームを交差させます。交点で真空からエネルギーが爆発的に出ます。空気が瞬時に超高温になります。熱い空気は上昇します。低気圧域（嵐の真空）が作られます。
- **冷モード（吸熱）：** スイッチを切り替えます。交点で真空がエネルギーを吸い込みます。空気が瞬時に凍ります。冷たい空気は沈みます。高気圧域（シールド）が作られます。

1. 冷モードで片側に重い空気の壁を築きます。
2. 熱モードで反対側に真空の穴を作ります。
3. 嵐は自然に冷側から熱側へ坂を滑り降ります。

天候を「強制」しません。道を作るだけで、天候は自ら走ります。
