# 時間は地図である — 物理学証明

> 📜 **作中文書。** これは2420年アーカイブの論証であり、物語の一部として残されています。科学的な意味での証明ではありません。この論証がどこで破綻するかを含む、検証済みの版は [SCIENCE.md](SCIENCE.md) にあります。

## 8歳児向け
「時間は動かない；あなたが動くんだ。過去は通りの下、未来は通りの上。どちらも今そこにある — まだ見ていないだけ。」

## 主題
クロノ位相幾何学と振動する時間。

## 公理
時間は滑らかに流れる川ではなく、急速な振動（波）である。私たちは正の拍（創造）だけを知覚し、その間の負の拍（破壊）を見逃す。

## メカニズム
現実は映画プロジェクターのよう：フレームが閃く（正の時間）、シャッターが閉じる（負/知覚されない）、次のフレームが閃く。連続性は高周波の点滅が作る錯覚である。

## 含意
過去と未来がこの振動の座標なら、時間旅行は位相シフト — 波の別の部分に合わせて点滅率を変えることである。
